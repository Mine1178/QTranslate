## ✨ 为什么选择 QTranslate？

| | **QTranslate** | 传统翻译工具 |
|---|---|---|
| 🚀 **启动速度** | 秒开，无等待 | 3-5 秒启动 |
| 💾 **内存占用** | ~50 MB | 200-500 MB |
| 📦 **安装包** | ~20 MB | 100+ MB |
| 🎯 **专注度** | 只做翻译，不臃肿 | 塞满用不上的功能 |
| 🎨 **界面** | 现代 Fluent 设计 | 老旧 Windows 风格 |

> **砍掉 OCR、砍掉截图翻译、砍掉冗余功能**——只留你真正每天都在用的翻译能力。

## 🚀 快速开始

### 下载

前往 [Releases](https://github.com/Mine1178/QTranslate/releases/latest) 下载最新版：

| 版本 | 适用场景 |
|---|---|
| **Setup.exe 安装包** ⭐ | 推荐，双击安装，自动创建快捷方式 |
| 便携版 | 绿色免安装 |

### 三步上手

1. **安装 / 解压**
2. 启动后软件安静躺在系统托盘 🔔
3. 选中任意外文 → 自动弹出翻译结果

> 首次启动自动预置默认服务：金山词霸翻译 / Edge TTS / 欧路词典生词本，开箱即用。

---

## ⌨️ 默认快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Enter` | 呼出输入翻译 |
| `Ctrl + Shift + Q` | 显示/隐藏主窗口 |
| `Alt + Q` | 划词翻译热键 |

> 全部可在「设置 → 热键」中自定义。

## 🛠 从源码构建

```bash
git clone https://github.com/Mine1178/QTranslate.git
cd QTranslate/src
dotnet build STranslate/STranslate.csproj -c Release
```
