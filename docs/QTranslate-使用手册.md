# QTranslate 用户使用手册

版本：V1.0.1  
更新日期：2026-10-18  
适用平台：Windows 10 / 11（x64）

---

## 一、软件简介

QTranslate 是一款轻量级桌面翻译工具，基于开源项目 STranslate 二次开发。专注划词翻译与输入翻译，启动快、占用小，常驻系统托盘。

**核心能力：**
- 选中屏幕任意文字，自动弹出翻译结果
- 手动输入文本即时翻译
- 支持百度、DeepL、Google、OpenAI、微软、有道等多引擎
- TTS 语音朗读
- 生词本、历史记录
- 全局快捷键自定义

## 二、安装与卸载

### 2.1 安装

**方式一：安装包（推荐）**

双击 `QTranslate-v1.0.1-setup.exe`，按向导选择安装目录完成。默认创建桌面快捷方式。

**方式二：便携版**

解压 `QTranslate-便携版.zip` 到任意目录，双击 `QTranslate.exe` 即用。注意：便携版需要系统已安装 .NET 10 桌面运行时。若未安装，程序启动时会弹窗引导你自动下载。

**方式三：单文件版**

解压 `QTranslate-单文件版.zip`，双击 `QTranslate.exe` 即用。自带运行时，无需额外安装。

### 2.2 首次启动

软件启动后**默认隐藏在系统托盘**，不会弹出主窗口。在屏幕右下角托盘区找到 QTranslate 图标：

- **左键单击**图标：显示/隐藏主翻译窗口
- **右键单击**图标：打开菜单（显示主界面、重置窗口位置、退出）

### 2.3 卸载

- 安装版：控制面板 → 程序和功能 → 找到 QTranslate → 卸载
- 便携版/单文件版：直接删除整个文件夹即可

> **注意：** 用户配置保存在 `%AppData%\STranslate\` 目录下，卸载软件不会自动删除配置。如需彻底清理，请手动删除该目录。

## 三、快速上手

### 3.1 划词翻译

1. 在浏览器、Word、PDF 阅读器等任何软件中，用鼠标选中一段外文
2. 软件会自动识别选区，短暂延迟后弹出翻译浮窗
3. 浮窗内显示原文、译文、朗读按钮

### 3.2 输入翻译

1. 按快捷键 `Ctrl + Enter`（默认）呼出输入窗口
2. 在输入框粘贴或输入要翻译的文本
3. 翻译结果实时显示在下方

### 3.3 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Enter` | 呼出输入翻译窗口 |
| `Ctrl + Shift + Q` | 显示/隐藏主界面（可自定义） |

> 可在「设置 → 快捷键」中修改为自己习惯的按键。

## 四、设置项说明

打开主界面后，点击右上角齿轮图标进入设置。左侧导航栏：

### 4.1 通用设置

- **开机自启动**：开机时自动运行 QTranslate
- **主题切换**：浅色 / 深色 / 跟随系统
- **数据目录**：打开配置文件夹
- **便携模式**：配置保存在软件目录，方便 U 盘携带

### 4.2 翻译设置

配置翻译引擎。首次使用需添加并选择默认引擎：

- **百度翻译**：需在百度翻译开放平台申请 AppID 和密钥
- **DeepL**：免费/付费 API Key
- **Google**：内置接口，无需密钥
- **OpenAI**：填入 API Key，支持 GPT 系列
- **微软翻译**：内置
- **有道**：需申请密钥

**操作方式：** 在引擎卡片中填入密钥，点击「启用」，然后设为默认引擎。

### 4.3 TTS 朗读

使用 Microsoft Edge 语音引擎朗读翻译结果，支持多种语言声音。无需额外配置。

### 4.4 生词本

划词翻译时点击「收藏」按钮，单词会存入生词本。在「生词本」页面可查看、搜索、删除。

### 4.5 独立翻译窗口

设置独立悬浮窗的位置、大小、触发方式。

### 4.6 历史记录

自动记录所有翻译过的文本，支持搜索和重新翻译。

### 4.7 插件管理

支持拖拽 `.spkg` 文件到窗口安装插件。插件扩展翻译引擎和功能。

### 4.8 快捷键

自定义所有全局快捷键。点击对应输入框后按下新的组合键即可。

### 4.9 关于

- 查看软件版本
- 点击「GitHub」查看开源仓库
- 点击「Issue」反馈问题
- 点击「☕ 赞助作者」支持开发

## 五、备份与恢复

在「设置 → 关于 → 备份」中：

- **创建备份**：将当前配置打包为 `.BACKUP` 文件
- **恢复备份**：选择之前的备份文件，一键还原配置

支持 WebDAV 云同步，可将备份存到网盘。

## 六、常见问题

**Q：启动后看不到窗口？**  
A：软件默认隐藏在托盘。看屏幕右下角，找到 QTranslate 图标，左键单击呼出。

**Q：划词翻译不弹窗？**  
A：检查「设置 → 翻译设置」中划词翻译是否启用；确认快捷键没被其他软件占用。

**Q：翻译失败/报错？**  
A：检查网络连接；确认对应翻译引擎的 API Key 已正确填写；切换其他引擎试试。

**Q：提示缺少 .NET 运行时？**  
A：便携版用户需手动安装 .NET 10 桌面运行时。弹窗中点「是」会自动通过 winget 下载安装。

**Q：如何切换中英文界面？**  
A：跟随系统语言，目前支持简体中文和英文。

**Q：软件占用资源高吗？**  
A：常驻内存约 50-80MB，空闲时 CPU 占用接近 0。
